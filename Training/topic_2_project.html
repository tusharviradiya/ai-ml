Mini Shop Billing Counter

A visual guide to Conditional Statements and Loops in Python

1. The Problem

You work at a small shop. A customer keeps adding items to their bill. Your program must do three things:

  • Repeat the question "What else would you like?" until the customer says done. Loop
  • Decide the discount based on how many of one item were bought. Conditionals
  • Decide whether delivery is free based on the final total. Conditionals

Real shops do exactly this. The topics are not just theory; they are the tools that make the counter work.

2. The Two Tools You Will Use

Conditional Statements

Idea: Make a decision. Do something only if a condition is true.

Real life: "If it rains, take an umbrella. Otherwise, wear sunglasses."

if qty >= 5:
    discount = 10
elif qty >= 3:
    discount = 5
else:
    discount = 0

Loops (for, while)

Idea: Repeat an action without writing it again and again.

Real life: "Keep scanning items until the cart is empty."

# while: repeat until a condition stops it
while item != "done":
    ...

# for: repeat once for each item in a list
for item in items:
    print(item)

6. The Core Code (Read It Slowly)

bill = 0

while True:                              # Loop: repeat until "done"
    item = input("Item name (or 'done'): ")
    if item == "done":                   # Decision: stop the loop?
        break

    price = float(input("Price: "))
    qty = int(input("Quantity: "))
    total = price * qty

    if qty >= 5:                         # Decision: discount tier
        total = total * 0.90
    elif qty >= 3:
        total = total * 0.95

    bill = bill + total

if bill > 1000:                          # Decision: delivery fee
    delivery = 0
else:
    delivery = 50

print("Final bill:", bill + delivery)

Tip: Read the code next to the flowchart. Each if matches a yellow diamond. Each while matches a purple loop.

8. Your Task

  1. Keep asking for items in a while loop until the customer types done.
  2. For each item, ask for price and quantity, then calculate its total.
  3. Use if / elif / else to apply the right discount tier.
  4. Add each item total to the bill.
  5. After the loop, use an if / else to add or skip the ₹50 delivery fee (free if bill is above ₹1000).
  6. Print the final bill.
