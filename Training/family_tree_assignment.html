Assignment: Create a Family Tree

Multilevel Inheritance in Python · Level: Junior · Estimated time: 2 to 3 hours

1. Problem Statement

A family wants a small program that describes its family tree. Each generation inherits traits from the generation before it.

The tree has three generations:

  • Grandparent: knows the family surname and where the family comes from.
  • Parent: inherits everything from the Grandparent, and adds education and a profession.
  • Child: inherits everything from the Parent, and adds hobbies and a school.

You will build this as three classes that form a chain: Child → Parent → Grandparent. This pattern is called multilevel inheritance.

Goal: By the end, you should be able to create a chain of classes where each child class reuses its parent's code using super(), and where one method can read data from every generation.

Topics covered: ClassesObjectsInheritancesuper()MethodsAttributes

3. Your Task

  1. Grandparent class. Create a class Grandparent with an __init__ that takes surname and origin. Add a method family_origin() that returns a sentence such as "The Sharma family comes from Gujarat."
  2. Parent class. Create a class Parent that inherits from Grandparent. Its __init__ takes surname, origin, education and job. Call super().__init__() to set the Grandparent's attributes. Add a method profession() that returns a sentence using the job and education.
  3. Child class. Create a class Child that inherits from Parent. Its __init__ takes all the Parent's inputs plus hobbies (a list) and school. Call super().__init__() to set the Parent's attributes. Add a method current_school() that returns a sentence about the school.
  4. Create one Child object with sample values for every field, and call each method once to check it works.
  5. Challenge (see Section 5). Add a method family_history() to Child that prints the full family history.
