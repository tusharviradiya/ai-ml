Assignment: Employee Management System

Class, Static and Instance Methods in Python · Level: Junior · Estimated time: 2 hours

1. Problem Statement

A small company wants a simple program to keep track of its employees. Every employee has an ID, a name and a salary. The program must be able to:

  • Add a new employee to a shared list, giving each one a unique ID. Class method
  • Calculate the average salary of all employees, without creating an employee object first. Static method
  • Show one employee's details on screen. Instance method

Your job is to write one class called Employee that does all three jobs.

Goal: By the end, you should understand which kind of method to choose for a job, and why the first parameter (self, cls, or nothing) matters.

Topics covered: ClassesObjectsClass attributes@classmethod@staticmethodInstance methods

3. Your Task

  1. Create the class. Write a class called Employee. Inside it, create a class-level list called employees that starts empty, and a class-level counter called next_id that starts at 1.
  2. Class method: add an employee. Write add_employee(cls, name, salary) with the @classmethod decorator. It must give the new employee the next unique ID, increase the counter, create an Employee object, add it to cls.employees, and return it.
  3. Static method: average salary. Write average_salary() with the @staticmethod decorator. It must return the average salary of all employees in Employee.employees. If there are no employees, it should return 0 instead of crashing.
  4. Instance method: display details. Write display_details(self). It must print the employee's ID, name and salary on one line.
  5. Test it. Add at least three employees, print the average salary, and display the details of each employee.

6. Quick Reference: Which Method Type?

Method typeFirst parameterCan use the object's own data?Can use class data?How it is called
Instance methodselfYesYesemp.display_details()
Class methodclsNoYesEmployee.add_employee(...)
Static methodnoneNoNo (only by name)Employee.average_salary()

Rule of thumb: use a class method when you need the class (to create objects or change class data), a static method when the code needs neither, and an instance method when it needs one specific object.

9. Hints If You Get Stuck

Two employees get the same ID. Check that next_id is a class attribute and that you write to it through cls.next_id (or Employee.next_id). If it is set inside __init__, each object gets its own copy.

Error: NameError: name 'self' is not defined inside a class method. Class methods receive cls, not self. Rename the parameter and use cls inside the method.

Error: ZeroDivisionError in average_salary. You are dividing by the number of employees when the list is empty. Check the length first and return 0.

Error: TypeError: average_salary() takes 0 positional arguments but 1 was given. Check that the static method has no self parameter and that you call it on the class, not on an object.

Ask a mentor after you have tried for at least 30 minutes. Bring your code, the error message, and what you expected to happen.
