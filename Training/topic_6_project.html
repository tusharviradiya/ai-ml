Mini Movie Ticket Booking

A visual guide to Instance Methods, Class Methods, Property Methods and Static Methods

1. The Problem

A cinema wants a small booking program. Each ticket needs to:

  • Know its own seat and price, and apply its own discounts. Instance method
  • Be created from a text line such as Dune|A12|300 from the booking system. Class method
  • Keep the seat valid and show the price with tax as if it were a simple value. Property
  • Check whether a seat code like B7 is valid, without needing any ticket at all. Static method

Every method type answers one question: what does this method need to know?

2. The Four Method Types

Instance Methods

Idea: Work on one specific object. The first parameter is self.

Real life: "this ticket's discount" depends on this ticket only.

def apply_discount(self, percent):
    self._price = self._price * (1 - percent / 100)

ticket.apply_discount(10)

Class Methods

Idea: Work on the class itself. The first parameter is cls. Often used to create objects in a new way.

Real life: a "factory" that builds a ticket from a booking line.

@classmethod
def from_text(cls, text):
    movie, seat, price = text.split("|")
    return cls(movie, seat, int(price))

Property Methods

Idea: Use a method like a plain attribute, with extra checks or calculations behind it.

Real life: a bank app shows your balance as a number, but calculates it safely behind the scenes.

@property
def price_with_tax(self):
    return self._price * 1.18

ticket.price_with_tax    # no brackets

Static Methods

Idea: A helper that belongs to the class for tidiness, but needs neither self nor cls.

Real life: a rule printed on the ticket counter that anyone can read.

@staticmethod
def is_valid_seat(seat):
    return seat[0] in "ABCDEFGH" and seat[1:].isdigit()

MovieTicket.is_valid_seat("B7")   # no object needed

8. The Core Code (Read It Slowly)

class MovieTicket:
    tickets_sold = 0                            # class data, shared by all tickets
    TAX_RATE = 0.18

    def __init__(self, movie, seat, price):
        self.movie = movie
        self.seat = seat                        # goes through the property setter
        self._price = price
        MovieTicket.tickets_sold += 1

    # ----- instance method: works on ONE ticket -----
    def apply_discount(self, percent):
        self._price = self._price * (1 - percent / 100)

    def describe(self):
        return f"{self.movie} | seat {self.seat} | ₹{self._price}"

    # ----- class method: works on the CLASS -----
    @classmethod
    def from_text(cls, text):
        movie, seat, price = text.split("|")
        return cls(movie, seat, int(price))

    @classmethod
    def total_sold(cls):
        return cls.tickets_sold

    # ----- property: attribute-style access with checks -----
    @property
    def seat(self):
        return self._seat

    @seat.setter
    def seat(self, value):
        if not MovieTicket.is_valid_seat(value):  # calls the static method
            raise ValueError("Seat must look like A1 to H20")
        self._seat = value

    @property
    def price_with_tax(self):
        return self._price * (1 + MovieTicket.TAX_RATE)

    # ----- static method: a helper that needs no self or cls -----
    @staticmethod
    def is_valid_seat(seat):
        return len(seat) >= 2 and seat[0] in "ABCDEFGH" and seat[1:].isdigit()

Notice how the methods depend on each other: the property setter uses the static method, and the class method creates objects through cls(...).

9. Your Task

  1. Create a MovieTicket class with movie, seat and price. Keep a class-level counter of tickets sold.
  2. Write an instance method apply_discount(percent) that changes only that ticket's price.
  3. Write a class method from_text(text) that reads a line like Dune|A12|300 and returns a ticket. Also add total_sold().
  4. Write a static method is_valid_seat(seat) that returns True for codes like A1 to H20.
  5. Write a property seat whose setter uses is_valid_seat() to reject bad codes.
  6. Write a read-only property price_with_tax that adds 18% tax.
  7. Create at least three tickets (two by normal creation and one with from_text) and print each one's details.

10. Acceptance Criteria (Tick As You Go)

total_sold() counts tickets created by both normal creation and from_text().
is_valid_seat() accepts A1 and H20, and rejects Z9, A and B-7.
Setting ticket.seat = "Z9" raises an error with a clear message.
price_with_tax is read without brackets, and assigning to it gives an error.
The program runs without errors for at least two different booking lists.
You can explain in your own words what self, cls and "nothing" each give a method.
